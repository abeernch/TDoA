This folder contains a 2D TDoA multisolutions workflow focused on isochrones
and repeated-baseline comparison.

Highlights:

1. Works with arbitrary sensor and emitter counts.
2. Supports 2D TDoA solutions and isochrones.
3. Can be used with time-varying emitters.
4. Produces multiple candidate solutions when the geometry is ambiguous.

The scripts in this folder explore how additional baselines can be compared to
reject inconsistent candidate solutions.
